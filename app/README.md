# SalesRadar MVP

A minimal, shippable platform for seller onboarding, learning, and opportunity discovery. Built with Next.js 15 + Convex.

## Features

### Core Functionality (MVP Scope)
- **Seller Onboarding**: Create a handle, get an adminKey, update profile
- **Learning System**: Complete 5 lessons and get certified
- **Opportunities Feed**: Browse and click on latest opportunities
- **Discovery**: Public directory of certified sellers by niche
- **Leaderboard**: Ranked sellers by activity (lessons + clicks)

### Out of Scope (MVP)
- No authentication flows (uses simple adminKey pattern)
- No dashboards
- No notifications
- No chat features
- No payout logic

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Database**: Convex (real-time serverless)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Runtime**: Node.js 20+

## Prerequisites

- Node.js 20 or higher
- npm or pnpm
- No API keys required for local development!

## Getting Started

### 1. Install Dependencies

```bash
cd app
npm install
```

### 2. Set Up Convex

Initialize Convex (this will create a local development deployment):

```bash
npx convex dev
```

This will:
- Create a `.env.local` file with `NEXT_PUBLIC_CONVEX_URL`
- Start the Convex development server
- Watch for schema and function changes

**Keep this terminal running!**

### 3. Seed the Database

In a new terminal, run the seed script:

```bash
npm run seed
```

This will populate:
- 5 lessons (Intro to Sales, Prospecting, Objections, Closing, Relationships)
- 20 sample opportunities from various sources

### 4. Start the Development Server

In another terminal:

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)

## Environment Variables

Create a `.env.local` file (automatically created by `npx convex dev`):

```env
# Development mode - enables localStorage for adminKey
NEXT_PUBLIC_DEV_MODE=true

# Convex URL (auto-generated by convex dev)
NEXT_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud
```

**Note**: No external API keys are required for the MVP!

## Usage Guide

### Creating Your First Seller

1. Visit `/start`
2. Fill in:
   - Handle (unique username)
   - Email (optional)
   - Niches (comma-separated, e.g., "SaaS, E-commerce")
   - Bio (optional)
3. Click "Create Account"
4. **IMPORTANT**: Copy and save your admin key! You'll need it to:
   - Update your profile
   - Complete lessons
   - Get certified

In DEV_MODE, the key is automatically saved to localStorage for convenience.

### Completing Lessons

1. Visit `/lessons`
2. Enter your admin key (auto-filled in DEV_MODE)
3. Click "Complete" on each lesson
4. After completing all 5 lessons, click "Check Certification Status"
5. You'll be certified and appear in the directory!

### Browsing Opportunities

1. Visit `/opps`
2. (Optional) Enter your handle to track clicks
3. Click "View Opportunity →" on any listing
4. This records a click (worth 1 point) and opens the URL

### Viewing the Directory

1. Visit `/dir`
2. See all certified sellers with their niches
3. Only certified sellers appear here

### Checking the Leaderboard

1. Visit `/leaderboard`
2. See rankings based on:
   - 10 points per completed lesson
   - 1 point per opportunity click
3. Top 3 get medal icons 🥇🥈🥉

## Troubleshooting

### "Cannot find module '@/convex/_generated/api'"

Run `npx convex dev` first. This generates the API types.

### "CONVEX_URL not found"

Make sure `npx convex dev` is running. It creates `.env.local` automatically.

### No lessons or opportunities showing

Run `npm run seed` to populate the database.

### Admin key not working

Make sure:
1. You copied the full key (starts with `sk_`)
2. You're using the same key that was generated
3. In DEV_MODE, check localStorage for the saved key

## Production Deployment

### Deploy to Vercel

1. Push to GitHub
2. Import to Vercel
3. Set environment variables:
   ```
   NEXT_PUBLIC_DEV_MODE=false
   ```
4. Connect Convex deployment:
   ```bash
   npx convex deploy
   ```
5. Copy the production URL to `NEXT_PUBLIC_CONVEX_URL` in Vercel

### Production Scrapers

Implement real scrapers in `scripts/`:
- LinkedIn Jobs API integration
- Indeed scraper
- RSS feed parsers
- Schedule with cron (Vercel Cron or GitHub Actions)

## Architecture Decisions

### Why adminKey instead of auth?
Simplifies MVP. No auth provider needed, faster development, and good enough for early validation.

### Why Convex?
Real-time updates, serverless, TypeScript-native, excellent DX, and no infrastructure management.

### Why no external APIs?
Can run and develop completely offline. No API key management. Faster iteration.
